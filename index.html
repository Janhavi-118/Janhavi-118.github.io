Research

I am interested in how intelligent systems build internal representations of space and experience from physical interaction, and how those representations support planning, adaptation, and robust behavior in the real world.

My work spans geometric perception for embodied agents, biologically grounded learning dynamics, and decentralized coordination in multi-robot systems. A recurring theme is how structure, whether physical, temporal, or biological, can constrain and guide learning rather than leaving it entirely to data.

I am currently drawn to computational neuroscience approaches to spatial intelligence, particularly how place cell and grid cell representations emerge from experience, and how the structure of that experience shapes what a network learns to encode.

NS-DART: Bridging Spatiotemporal Graph Networks and Physics-Informed Reasoning for Explainable Robotic Diagnostics
Under Review — IEEE Robotics and Automation Letters (RA-L)
Code

NS-DART is a scalable 4-tier neuro-symbolic framework for explainable diagnostics on warehouse AMR fleets. It bridges spatiotemporal graph-based anomaly detection with deterministic physics-informed reasoning, governed by a declarative YAML ontology. A novel context-key calibration mechanism conditions anomaly thresholds on the robot's behavioral state, reducing false alarm rates by 48% compared to global threshold baselines. A symbolic physics engine maps detected anomalies to causal fault trees, achieving a 97.7% explanation rate, and LLM generation is strictly bounded to verified fault trees to prevent hallucination.

  • Context-key calibration: per-context anomaly thresholds across 7 operational states, with 9x variation in threshold values
  • Epistemic separation principle: PARTIAL_DIAGNOSTIC output when anomaly cannot be physically explained
  • 0.982 precision and 97.7% explanation rate on real warehouse AMR telemetry
  • 35.5% more faults detected than MTAD-GAT neural baseline
SGSPose: Neuromorphic-Geometric 6D Pose Estimation Through Spiking Graph Neural Networks and SE(3)-Equivariant Learning
IEEE Access
Paper Code

SGSPose integrates spiking neural networks for temporal spike encoding with SE(3)-equivariant graph neural networks for geometrically consistent 6D pose regression. The pipeline converts RGB images into temporal spiking features, followed by SE(3)-equivariant graph message passing with orthogonalized rotation outputs, achieving physically consistent pose estimation that respects the geometry of 3D space by construction.

  • Novel integration of neuromorphic spike encoding with SE(3)-equivariant geometric reasoning
  • Over 90% improvement in median translation error on 7Scenes compared to PoseNet
  • Translation errors as low as 0.019m; ADD-S accuracy up to 96.2%
  • Composite loss combining Smooth L1, geodesic rotation distance, and ADD-S metric
SwarmFormer: Transformer-Based Multi-Robot Formation Control With Risk-Aware Fusion
RCAE 2025
Paper Code Dataset

SwarmFormer is a goal-conditioned transformer policy for decentralized multi-robot formation control. It fuses odometry, CVaR-augmented LiDAR, explicit formation goals, and decentralized gossip communication via hierarchical cross-modal attention, with Gaussian Mixture Model outputs for uncertainty-aware control. Trained and evaluated on a comprehensive Gazebo-ROS2 dataset covering 5 formation types and 4 swarm sizes.

  • Hierarchical cross-modal attention over heterogeneous sensor modalities
  • CVaR-augmented LiDAR for risk-aware obstacle fusion
  • Test MAE of 0.0767, improving 21% over MLP and 28% over RNN baselines
  • NLL of -3.67, enabling uncertainty-aware decentralized control
Dopamine in the Mitigation of Catastrophic Forgetting in Reinforcement Learning
MLISE 2025
Paper Code

This work develops dopamine-inspired reinforcement learning methods that integrate Elastic Weight Consolidation, neuromodulated temporal difference updates, and Hebbian learning to stabilize DQNs across sequential Atari tasks. The key contribution is dopamine-gated synaptic consolidation, which achieves near-zero catastrophic forgetting while reinforcing prior knowledge during new task learning.

  • Dopamine-gated synaptic consolidation: Backward Transfer = 0, near-zero forgetting
  • Greater than 99% reduction in weight changes compared to baseline DQN
  • Positive backward transfer (+10) with neuromodulated learning rate
  • Validated across sequential Atari task benchmarks
Autonomous Exploration of Unknown Indoor Environments Using Multi-UAV Systems
ICCCR 2025
Paper Pygame Gazebo

A coordinated multi-UAV swarm system for autonomous indoor exploration using a master-slave architecture with dynamic task allocation and safety-aware coordination via ROS2. The system integrates PX4 autopilot, Gazebo simulator, and ROS2 middleware for GPS-denied navigation using LiDAR-based SLAM and Visual-Inertial Odometry.

  • Master-slave architecture with dynamic floor assignment and recursive frontier exploration
  • Battery-aware autonomous return and adaptive swarm formation
  • GPS-denied navigation via LiDAR SLAM and Visual-Inertial Odometry fusion
  • High-fidelity validation in Gazebo-ROS2 with PX4 autopilot integration
